# 승인 대기 제안

[English](README.md)

<a id="state"></a>
## 현재 상태

승인 대기 제안은 없습니다. 현재 계약은 [spec](../spec/json-contract.ko.md)에서 관리합니다.

<a id="procedure"></a>
## 제안 절차

각 제안에는 영어 문서, 한국어 번역, 문제, 제안 계약, 대안, 인수 기준, 구현 영향, 명시적인 승인 대기 상태가 필요합니다.

승인 후 관련 명세와 기능 상태를 갱신하고 제안 파일과 목록 항목을 제거합니다. 제안을 구현된 동작으로 설명하지 않습니다.
