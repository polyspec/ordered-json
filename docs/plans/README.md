<a id="procedure"></a>
## Proposal procedure

Each proposal requires an English document, a Korean translation, a problem statement, a proposed contract, alternatives, acceptance criteria, implementation impact, and an explicit pending approval state. Register both files in the [manifest](../documentation-manifest.json).

After approval, update the applicable specification and feature state, then remove the proposal files and their manifest entry. Do not present a proposal as implemented behavior.
