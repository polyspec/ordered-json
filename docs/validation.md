같은 공식 예제 17개, 저장소 공통 문법 사례 98개, JSONTestSuite 318개를 [단일 검증기](../scripts/verify.py)로 검사했습니다. 각 언어는 입력을 처리하고 결과를 반환하는 어댑터만 제공합니다.

객체를 연관배열로 변경하고, 같은 키의 값만 덮어쓰며 최초 위치를 유지하도록 구현과 기대값을 수정했습니다. `{"b":1,"a":2,"b":3}`은 `{"b":3,"a":2}`가 됩니다. 기본 직렬화도 입력 원문 반환에서 연관배열의 JSON 출력으로 바뀌었으며, 중복 조회용 `getAll`과 `Member` 목록 API는 제거했습니다.

공식 기대 결과는 [examples/official.json](../examples/official.json)에 고정되어 있습니다. 추가 문법 사례는 Python 표준 JSON 디코더의 키·값 쌍 콜백 및 숫자 토큰 콜백을 이용한 독립 참조 결과와 비교합니다.

검사 범위는 유효·무효 입력 판정, 모든 깊이의 키·원소 순서, 마지막 값 조회, 기본 직렬화와 공백 없는 출력, 연관배열·원소 배열을 통한 재구성입니다. 재구성 시 키를 처음 순서대로 넣고 역순으로 값을 덮어써도 순서가 유지되는지 검사합니다. 재구성한 JSON은 공통 검증기의 독립 파서로 읽어 고정된 기대 트리와 비교합니다.

외부 자료: [JSONTestSuite, commit 1ef36fa01286573e846ac449e8683f8833c5b26a](https://github.com/nst/JSONTestSuite/tree/1ef36fa01286573e846ac449e8683f8833c5b26a). `i_` 입력은 UTF-8 검사와 최대 깊이 256이라는 이 구현의 정책을 적용했습니다.

```sh
python3 scripts/test.py --suite .cache/JSONTestSuite
```

이 결과는 위 환경과 사례에 대한 검증 기록입니다. 선언된 최소 런타임 버전 전체에서 실행한 결과는 아닙니다.

동일한 입력으로 실행한 기존 Python·Erlang 프로젝트 결과는 [ojson 비교 검증](ojson-comparison.md)에 별도로 기록했습니다.
